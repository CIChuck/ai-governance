# Agentic Architecture Governance Framework

This repository contains the current working manuscript of the Agentic Architecture Governance Framework (AAGF), a practitioner's reference for enterprise AI governance.

## Current document

- [AAGF R23](docs/AAGF_R23.docx) — the current Word manuscript, labeled *First Edition, Version 1.0, current as of November 2026* within the document.

The manuscript still contains tracked changes and editorial notes. Its version label records the document's own designation; this repository does not yet mark it as a clean publication release.

Earlier draft files remain in the local workspace under `docs/versions/`, along with `docs/aaf_document.docx`. They are excluded from this initial repository snapshot so the current manuscript is unambiguous.

## Repository scope

This is a document repository. There is no application code or test suite. Changes to the manuscript should preserve the DOCX source and record the reviewed release in Git history.
